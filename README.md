# Portfólio — João Victor

Site pessoal de portfólio, desenvolvido com HTML, CSS e JavaScript puros.

## 🔗 Ver online

Ative o GitHub Pages em **Settings → Pages → Branch: main → / (root)** e o site ficará disponível em:

```
https://victordev373.github.io/PORTIFOLIO/
```

## ✨ Seções

- **Início** — apresentação com efeito de digitação e redes sociais
- **Sobre** — resumo profissional e estatísticas
- **Habilidades** — HTML, CSS, JavaScript, React, Git/GitHub e Python
- **Projetos** — destaque para repositórios reais do GitHub:
  - [Quero Mais Viagens](https://github.com/Victordev373/quero-mais-viagens)
  - [Serv Saúde](https://github.com/Victordev373/Serv-Sa-de)
  - [Front-End Lab](https://github.com/Victordev373/Projeto-FrontEnd-Lab)
- **Contato** — e-mail, GitHub, LinkedIn e Instagram

## 🛠️ Tecnologias

- HTML5 semântico
- CSS3 (Flexbox, Grid, animações, tema escuro)
- JavaScript puro (scroll reveal, contadores animados, efeito de digitação, menu responsivo)

## 📂 Estrutura

```
├── index.html
├── css/
│   └── style.css
├── js/
│   └── script.js
└── assets/
    └── img/
```

## 🚀 Rodando localmente

Basta abrir o `index.html` no navegador, ou servir a pasta com qualquer servidor estático:

```bash
npx serve .
```
